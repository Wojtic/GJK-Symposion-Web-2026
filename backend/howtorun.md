# How to run

### First we need to build it:
1) Download & Install a C and C++ compiler (ideally clang on linux and something in WSL on windows, alternatively MinGW on windows)
2) Download & Install CMake
3) Go into backend
4) Run `cmake -B build`
5) Once done open build folder and launch the native executable (ideally using PS or a terminal)
6) Run the frontend - hosting isn't yet a part of this.
